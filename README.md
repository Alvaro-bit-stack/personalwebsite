# Inside my head

My personal website: a 3D bust of me whose head opens up into a little room — a TV, a CD shelf with a working boombox, a computer with my projects, a phone to contact me, and Daisy the cat.

Built with [Three.js](https://threejs.org). Everything is static: `index.html` + `head.glb` + the media folders.

Run locally: `python -m http.server` in this folder, then open http://localhost:8000.
